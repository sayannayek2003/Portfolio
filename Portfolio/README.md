# Sayan Nayek - Personal Engineering & Data Science Portfolio

> Modern, responsive, cyber-dark glassmorphism portfolio crafted with clean HTML5, CSS3, and modern JavaScript. Showcasing expertise in Machine Learning, Data Analytics (Power BI), Data Structures & Algorithms (Java/C++), and Software Engineering.

---

## 🌟 Key Features

- **Cyber-Dark & Clean Light Mode**: Default dark theme with neon blue/cyan accents, glassmorphic panels, and a 1-click adaptive light theme toggle (persisted via `localStorage`).
- **Interactive Particle Constellation**: Responsive background HTML5 canvas particle network reacting subtly to cursor interactions.
- **Dynamic Typewriter & Animated Metrics**: Live typewriter hero effect and scroll-triggered counters for DSA problems solved (250+), HackerRank 5-star rating, and certifications.
- **Filterable Technical Arsenal**: Filter skills by category (Languages, ML & Data Science, Tools & Analytics, Core CS Concepts).
- **Featured Project Showcases**:
  - **Customer Segmentation using ML**: Unsupervised K-Means clustering with Elbow Method curve and interactive cluster plot visualization.
  - **Cryptocurrency Intelligence Dashboard**: Power BI analytics solution with simulated live KPI cards, DAX metrics, and time-series sparklines.
  - **Java Swing Snake Game**: Interactive playable in-browser retro arcade game illustrating Singly Linked List body coordinate shifting ($O(1)$ head insertion and tail deletion).
- **Interactive Modals & Clipboards**: 1-click copy-to-clipboard for Email and Phone with instant toast notifications.
- **Mobile-First Responsive Design**: Optimized across mobile phones, tablets, laptops, and ultra-wide displays.

## 🚀 How to Run Locally

You don't need any complex build tools or dependencies! You can run it directly:

### Option 1: Direct File Open
Simply double-click `index.html` or drag it into any modern web browser (Chrome, Edge, Firefox, Brave, Safari).

### Option 2: Local HTTP Server (Python)
If you prefer running a local development server:
```bash
python -m http.server 3000
```
Then visit: `http://localhost:3000`

### Option 3: Node.js (npx serve)
```bash
npx serve .
```

## 🌐 1-Click Deployment to GitHub Pages

1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release for Sayan Nayek"
   ```
2. Create a repository on GitHub (e.g. `sayannayek2003.github.io` or `portfolio`).
3. Push to your repository:
   ```bash
   git remote add origin https://github.com/sayannayek2003/portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. In GitHub: go to **Settings** > **Pages** > Select branch `main` and root `/` > Click **Save**. Your site will be live at `https://sayannayek2003.github.io/portfolio/`!
